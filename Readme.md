# Missionaries and Cannibals Game

A Python-based implementation of the classic **Missionaries and Cannibals River Crossing Puzzle**.

This project simulates the traditional river-crossing problem where three missionaries and three cannibals must cross a river safely using a boat that can carry a maximum of two people.

The main objective is to move everyone from the left bank to the right bank without violating the game rules.

## Project Overview

The Missionaries and Cannibals problem is a classic artificial intelligence and problem-solving puzzle.

The challenge is to find a sequence of valid boat movements that allows all six people to cross the river safely.

This project is developed using Python to understand problem-solving concepts, logical conditions, state transitions, and game validation.

## Game Rules

1. There are 3 Missionaries and 3 Cannibals on the left bank.
2. A boat is available to transport people across the river.
3. The boat can carry a minimum of one and a maximum of two people.
4. The boat cannot cross the river without passengers.
5. On either riverbank, cannibals must never outnumber missionaries when at least one missionary is present.
6. The game is completed when all missionaries and cannibals safely reach the right bank.
